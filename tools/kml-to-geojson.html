KML to GeoJSON Converter

Converts KML Placemarks into GeoJSON FeatureCollections ready for Leaflet, MapLibre, Mapbox, and modern web mapping APIs.

KML input

GeoJSON output

Answer-first

The abcGEO KML to GeoJSON Converter parses KML Placemark geometries (Point, LineString, Polygon, MultiGeometry) into a GeoJSON FeatureCollection with longitude-first coordinates.

Convert KML to GeoJSON for Leaflet and MapLibre

  • Reads standard OGC KML 2.2 Placemarks and nested MultiGeometry.
  • Maps Placemark name/description into GeoJSON properties.
  • Ideal before loading Earth exports into web map libraries.
  • Round-trip with GeoJSON to KML to validate interchange.

How to use this converter

  1. Paste KML XML or upload a .kml file (sample available).
  2. Click Convert to build a FeatureCollection.
  3. Download .geojson and load it in Leaflet, MapLibre, or QGIS.
  4. For KMZ archives, unzip first and convert the inner doc.kml.

Read the full format guide in the Complete Guide to Geographic Data Conversion, or browse every utility on tools.html.
