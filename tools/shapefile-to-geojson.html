Shapefile to GeoJSON Converter

Converts zipped ESRI Shapefile packages (.shp + .shx + .dbf, ideally with .prj) into GeoJSON FeatureCollections for web mapping.

Packaging reminder: A Shapefile is a multi-file format. Zip .shp, .shx, and .dbf together (add .prj and .cpg when you have them). Uploading only the .shp will fail.

Shapefile package notes

GeoJSON output

Answer-first

The abcGEO Shapefile to GeoJSON Converter reads a ZIP of Shapefile components in the browser and emits a GeoJSON FeatureCollection suitable for Leaflet, MapLibre, and open-data publishing.

Convert ESRI Shapefile ZIP to GeoJSON

  • Requires a ZIP with at least .shp, .shx, and .dbf together.
  • Include .prj whenever possible so CRS metadata travels with the package.
  • Client-side parsing via shpjs—no desktop GIS required.
  • Follow up with GeoJSON to KML or CSV for other handoffs.

How to use this converter

  1. Zip the full Shapefile set (.shp, .shx, .dbf, and preferably .prj / .cpg).
  2. Upload the .zip using Choose file, then click Convert.
  3. Inspect feature count in the status line and sample the GeoJSON output.
  4. If positions look wrong, reproject to WGS84 (EPSG:4326) in GIS before converting.
