How to Build Custom Interactive Maps Using Open-Source Tools

12 min read · Leaflet.js · Mapbox GL / MapLibre · abcGEO Editorial

Answer-first

Build interactive web maps by pairing a renderer (Leaflet or MapLibre/Mapbox GL) with clean GeoJSON, an open basemap, and purposeful popups—then scale with tiles when layers get heavy.

This tutorial is a supporting article under Pillar 2: Modern Web Mapping & Spatial Analysis. You will wire a map container, add a basemap, load GeoJSON, and choose when Leaflet is enough versus when a GL engine is worth the complexity.

1. Pick the right open-source renderer

Answer-first

Use Leaflet for lightweight marker/overlay maps; use MapLibre or Mapbox GL JS when you need vector styles, denser layers, or GPU-accelerated interaction.

If your product story is “show these places and let people click them,” start with Leaflet. If the story is “own the cartography and keep zooming buttery with many features,” plan for MapLibre/Mapbox GL. The pillar’s Leaflet and Mapbox GL sections unpack the trade-offs in depth.

2. Prepare GeoJSON the map can trust

Answer-first

Interactive maps fail loudly on swapped axes, invalid polygons, and bloated attributes—clean and convert inputs before you write map code.

  • Convert spreadsheets with CSV to GeoJSON.
  • Bring Earth exports across with KML to GeoJSON.
  • Unzip legacy GIS packages via Shapefile to GeoJSON.
  • Review format rules in Pillar 1’s GeoJSON section (longitude first).

3. Build a Leaflet map in four steps

Create the map shell

<div id="map" style="height: 420px;"></div>
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

Add an open basemap and center

const map = L.map('map').setView([37.7749, -122.4194], 12); // lat, lon
L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
  maxZoom: 19,
  attribution: '&copy; OpenStreetMap'
}).addTo(map);

Overlay GeoJSON with popups

fetch('/data/places.geojson')
  .then((res) => res.json())
  .then((data) => {
    L.geoJSON(data, {
      pointToLayer: (feature, latlng) =>
        L.circleMarker(latlng, {
          radius: 6,
          color: '#00B4D8',
          fillColor: '#FF6B4A',
          fillOpacity: 0.85
        }),
      onEachFeature: (feature, layer) => {
        const name = feature.properties?.name || 'Untitled';
        layer.bindPopup(`<strong>${name}</strong>`);
      }
    }).addTo(map);
  });

Production checklist for Leaflet

  • Set an explicit map height (or the map collapses to zero).
  • Call map.invalidateSize() if the container starts hidden (tabs/modals).
  • Cluster dense points before users see a pin blizzard.
  • Keep popup HTML minimal and escaped—treat properties as untrusted text.

4. Upgrade path: MapLibre / Mapbox GL

Answer-first

Move to a GL map when you need custom vector styles or when GeoJSON overlays become too heavy for Leaflet’s DOM/SVG model.

const map = new maplibregl.Map({
  container: 'map',
  style: 'https://demotiles.maplibre.org/style.json',
  center: [-122.4194, 37.7749], // lon, lat
  zoom: 11
});

map.on('load', () => {
  map.addSource('places', { type: 'geojson', data: '/data/places.geojson' });
  map.addLayer({
    id: 'places',
    type: 'circle',
    source: 'places',
    paint: {
      'circle-radius': 5,
      'circle-color': '#FF6B4A'
    }
  });
});

For dense polygons or nationwide layers, do not stop at GeoJSON sources—follow Optimizing Heavy GeoJSON for Faster Web Performance and serve tiles instead.

5. Wire analysis upstream (optional but powerful)

If features need buffers, filters, or joins before mapping, run that work in GeoPandas or PostGIS, then export a smaller layer for the client. The browser should present decisions, not recompute GIS homework on every page load.
